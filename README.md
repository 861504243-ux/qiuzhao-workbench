# 秋招作战台 · 2027 届校招求职工作台

面向 2027 届校招求职者的一站式求职工作台 —— **纯前端可交互原型**（模拟数据 + localStorage 持久化，演示模式自动脱敏）。

> 打开 `index.html`（或任意静态服务器托管该文件）即可体验全部六大模块，无需后端、无需构建。

## 六大模块

| 模块 | 能力 |
|---|---|
| 岗位雷达 | 12 个模拟岗位，支持企业性质 / 行业 / 岗位大类 / 地点 / 学历筛选，一键加入投递计划，详情弹窗 |
| 今日作战日历 | 按网申截止升序的时间轴，预警阈值可调（≤7 天橙 / ≤3 天红），与投递计划实时同步 |
| 定制简历 | 五步 AI 生成动画 + 岗位匹配度评分（86 分）+ 演示模式脱敏开关 + Word 导出 + 版本管理 V3/V2/V1 |
| 经历资产 | 初版简历拆解为教育 / 实习 / 项目 / 技能四卡，AI 教练 3 轮追问，可沉淀补充素材 |
| 面试作战 | 题库手风琴（行为 / 专业 / HR / 公司专属）、AI 模拟面试 3 题当场评分、每日 3 次配额（localStorage）、复盘录入、看板速览 |
| 知识库 | 文件 / 图片 OCR / 链接三种录入，关键词搜索 + 分类筛选，AI 问答附来源 |

## 快速开始

```bash
# 方式一：直接双击打开 index.html
# 方式二：静态服务器
python -m http.server 8910 --directory .
# 浏览器打开 http://localhost:8910/index.html
```

顶部工具栏可实时切换四种界面状态（有数据 / 空 / 加载 / 异常）。

## 技术说明

- 纯前端单页应用：HTML + CSS + 原生 JavaScript，无任何外部依赖
- 数据持久化：`localStorage`（投递计划、知识库、模拟面试配额）
- 所有图标为内联 SVG（Phosphor），视觉元素全部为 CSS/SVG 绘制，无外部图片
- 演示模式自动脱敏：姓名 / 电话 / 邮箱一键打码
- 界面数据均为演示示例数据（岗位、分数、日历为模拟值）

## 设计

- 风格：纸感亮场 + 衬线战报数字 + 森林绿指挥桌（唯一强调色 #2F6B4F）
- 四种状态色：青（正常）/ 橙（预警）/ 红（异常）/ 灰（禁用）
